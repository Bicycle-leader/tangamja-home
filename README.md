# 탄감자 2027 운영계획(안)

회원총회 및 운영위원회 검토용 업무보고를 웹으로 옮겼습니다. 표지에는 핵심 목표와 목차가 있으며, 운영 방향부터 성과·로드맵까지 일곱 주제를 각각 독립 페이지에서 볼 수 있습니다.

## 로컬에서 보기

Node.js가 있는 환경에서 아래 명령을 실행하고 브라우저에서 `http://127.0.0.1:4173/`을 엽니다.

```sh
node scripts/serve.mjs
```

`node scripts/build.mjs`는 별도 패키지 설치 없이 `dist/`에 정적 사이트를 생성합니다. 생성된 `dist/index.html`은 브라우저에서 직접 열 수도 있습니다.

## 운영계획 편집

- `src/content.mjs`에서 운영계획 내용과 숫자를 수정합니다.
- `src/styles.css`에서 인쇄용 스타일을 포함한 화면 디자인을 수정합니다.
- 내용을 편집한 뒤 사이트를 다시 빌드합니다.
